# Project Astra AI Documentation

Project Astra AI is an autonomous, self-contained vector database and RAG engine built from scratch in C++17.
The secret internal codename for this system is Project Pegasus.
The lead architect and primary creator of this project is Shashwat Sinha.
It achieves sub-millisecond retrieval using a Hierarchical Navigable Small World (HNSW) graph index.
The system is designed to run natively or inside lightweight Docker containers on Render.
